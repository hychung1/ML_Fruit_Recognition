========================================================================
  FRUIT & VEGETABLE RECOGNITION - HOW TO RUN THE PROJECT
========================================================================

There are two independent pipelines in this folder:
  A) Classical ML: HSV + HOG features -> KNN / SVM / Random Forest
     Scripts: classical_ml/
  B) Deep learning: EfficientNetB0 -> TFLite -> Flutter Android app
     Scripts: deep_learning/

Data folders (dataset/, results/, results_dl/, dl_model/, models/,
features/) stay at this level and are shared by both pipelines.

------------------------------------------------------------------------
0. PREREQUISITES
------------------------------------------------------------------------
* Python 3.12 (TensorFlow 2.20 does not support Python 3.13/3.14).
* Flutter SDK (only for the Android app).
* The Kaggle dataset, downloaded and extracted locally:
  https://www.kaggle.com/datasets/kritikseth/fruit-and-vegetable-image-recognition

  Required layout (36 class folders in each split):
      dataset/train/<class>/
      dataset/validation/<class>/
      dataset/test/<class>/

  dataset/, .venv/ and features/ are ignored by git and must be generated
  locally. models/ already contains the team's trained KNN/SVM/Random Forest
  models and scaler, so steps A3/A4 below can be skipped unless retraining.
  results/ and results_dl/ contain the reported charts and metrics.

Install Python packages from this folder:

    python312 -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt

(On macOS/Linux use: python3.12 -m venv .venv && source .venv/bin/activate
 && pip install -r requirements.txt)

------------------------------------------------------------------------
A. CLASSICAL ML PIPELINE (KNN, SVM, RANDOM FOREST)
------------------------------------------------------------------------
All commands are run from this folder (code/).

1) Exploratory data analysis - class counts, distribution chart, samples.
   Output: results/eda_distribution.png, results/eda_samples.png

    .venv\Scripts\python classical_ml\eda.py

2) Feature extraction - 512 HSV histogram + 288 HOG = 800 values per image.
   Cached in features/*_features.joblib; scaler saved to models/scaler.joblib.
   Only the training split is used to fit the StandardScaler (no leakage).

    .venv\Scripts\python classical_ml\feature_extraction.py

3) Train and tune each classifier. Each script prints test metrics and a
   classification report, saves a confusion matrix in results/, and writes
   its tuned model to models/<name>_model.joblib.

    .venv\Scripts\python classical_ml\train_knn.py
    .venv\Scripts\python classical_ml\train_svm.py
    .venv\Scripts\python classical_ml\train_rf.py

4) Compare the three models. Requires all three .joblib files from step 3.
   Output: results/metrics_summary.csv and results/comparison_chart.png

    .venv\Scripts\python classical_ml\compare_models.py

   Note: compare_models.py divides the total prediction time by 359, the
   number of images in the test split. Change that constant if your dataset
   has a different test size.

------------------------------------------------------------------------
B. EFFICIENTNETB0 + STREAMLIT + ANDROID APP
------------------------------------------------------------------------
1) (Optional) Inspect the data / generators used for the deep model:

    .venv\Scripts\python deep_learning\data_processing.py
    .venv\Scripts\python deep_learning\data_visualization.py

2) (Optional) Retrain EfficientNetB0 - two phases: frozen ImageNet base,
   then fine-tuning of the top layers. Best checkpoint is written to
   dl_model/efficientnet_b0_fruit_veg.h5:

    .venv\Scripts\python deep_learning\train_efficientnet.py

3) Evaluate the trained model on the test split. Prints accuracy, macro
   precision/recall/F1, a per-class report and saves a confusion matrix:

    .venv\Scripts\python deep_learning\eval_efficientnet.py

4) Web demo - upload a single image and see the top-3 predictions. Use the
   "Chọn mô hình dự đoán" dropdown to switch between EfficientNetB0, KNN,
   SVM and Random Forest. The classical options use the trained .joblib
   files in models/ and require no retraining:

    .venv\Scripts\python -m streamlit run deep_learning\app.py

5) Export for the Android app. Writes fruit_recognition_app/assets/
   fruit_model.tflite (float16, ~8 MB) and labels.txt, then verifies that
   TFLite and Keras agree on one test image from every class:

    .venv\Scripts\python deep_learning\convert_to_tflite.py

6) Run / build the Android app (Flutter SDK required):

    cd fruit_recognition_app
    flutter pub get
    flutter run
    flutter build apk --release --split-per-abi

   Use app-arm64-v8a-release.apk for modern phones. The APK is not kept in
   git; build it or use the release published on GitHub.

IMPORTANT: In Keras 3, efficientnet.preprocess_input does nothing - the
model performs rescaling/normalization internally. The converter and the
Flutter app both supply raw 0-255 RGB pixels. Do not normalize again.

------------------------------------------------------------------------
TROUBLESHOOTING
------------------------------------------------------------------------
* "No module named cv2" / "No module named skimage" / "No module named joblib"
  -> install the classical-ML dependencies: pip install -r requirements.txt
* "No matching distribution found for tensorflow" on Python 3.14
  -> use Python 3.12 for this project.
* app.py fails with "No module named tensorflow" (or the venv says
  "No module named streamlit")
  -> always start the web demo with:
     .venv\Scripts\python -m streamlit run deep_learning\app.py
  Global Python 3.14 has Streamlit but no TensorFlow; the .venv has
  TensorFlow and must have Streamlit installed from requirements.txt.
* Dataset paths not found -> confirm dataset/train, dataset/validation and
  dataset/test exist directly inside this code/ folder.
* GPU out of memory while training EfficientNetB0
  -> reduce BATCH_SIZE from 32 to 16 in deep_learning/train_efficientnet.py.
* Old cached features after editing the dataset
  -> delete the features/ folder and rerun classical_ml/feature_extraction.py.
